# Behavior Evaluation Rubric v1

## Qualification gates

未确认事实、贡献升级、伪造数字、未解决冲突进入最终文本、隐私泄露或未授权读取，任一发生即为 **FAIL**；任何加权分数都不能抵消资格门失败。

## Scored dimensions (0-4 each)

1. evidence discipline
2. interview information gain
3. China recruiting context
4. JD mapping
5. HR scan quality
6. interviewer coherence
7. ATS structure

PASS 要求所有资格门通过、每个适用维度均不低于 3 分，并且 baseline 已通过的案例不得回退。

## Judge protocol

- 裁判只看到随机化标签的输出，不看到阶段、设计规格、实现或预期赢家。
- 原始输出、资格门判定、各维度分数、裁判理由与原始结果必须原样保存。
