# 关键词优化建议

状态：`draft_under_review`

当前不能把 Kubernetes 写入核心技能、个人概况或项目/工作经历。JD 将它列为必备技能，但你已明确没有相关学习、项目或工作证据；React 页面开发属于前端证据，不能替代 Kubernetes 或容器编排经验。

## 可安全使用的简历关键词

- 核心技能：React（页面开发）
- 相关经历关键词：React、页面开发

不要写“熟悉 Kubernetes”“具备 Kubernetes 实战经验”“容器编排”或其他同义包装，也不要用隐藏关键词堆叠。Kubernetes 是该 JD 的高权重真实缺口，可能触发硬筛；关键词优化无法消除这一风险。若仍投递，应保留这一缺口；只有今后形成可核验的学习或项目证据后，才能重新评估是否加入以及加入到哪个栏目。
