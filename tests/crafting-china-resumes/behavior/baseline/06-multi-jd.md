### 产品经理版

**SaaS 后台产品与客户运营**

- 面向客户开展 SaaS 后台需求访谈，梳理业务流程、使用痛点及功能诉求，沉淀需求清单，为产品迭代提供输入。
- 使用 SQL 搭建业务看板，持续跟踪产品使用与客户续费相关指标，为需求优先级判断和客户沟通提供数据依据。
- 跟进客户续费进展，收集客户反馈及潜在流失原因，将一线信息反馈至产品优化环节。
- 串联“需求访谈—数据观察—续费反馈”，形成从用户需求到业务结果的闭环。

**一句话概述：** 兼顾用户需求与商业结果，能够通过访谈和数据分析推动 SaaS 后台产品优化。

### 数据分析师版

**SaaS 业务数据分析**

- 使用 SQL 对 SaaS 后台业务数据进行查询、汇总与分析，搭建可视化看板，支持核心指标的持续监控。
- 结合客户续费跟进信息，关注产品使用表现与续费状态，为识别续费风险和制定跟进策略提供数据支持。
- 参与客户需求访谈，将业务问题转化为数据分析需求，并通过看板呈现相关指标与趋势。
- 结合定量数据与客户定性反馈，为业务判断和产品改进提供分析依据。

**一句话概述：** 能够理解 SaaS 业务场景，使用 SQL 和可视化看板支持产品分析及客户续费决策。
